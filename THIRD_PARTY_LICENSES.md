`LICENSE.exception`). It does not bundle any of the packages below; they are
installed separately by the user. This list is informational, compiled from
the package metadata of the versions installed on 2026-09-18. Check each
project's own license file before redistributing a bundle.

## Optional colormap packages

Detected at start-up only if installed (`climcanvas/core/external_cmaps.py`).
A reproduction script imports one of them only when a colormap from that
package was chosen.

## Data

- Natural Earth (coastlines, borders and other map features downloaded by
  cartopy): public domain.
- `data/sample/*.nc` are synthetic files generated by `scripts/make_sample_*.py`
